# DC Circuit Calculator

โปรแกรมคำนวณวงจรไฟฟ้ากระแสตรง (DC Circuit Calculator) พัฒนาขึ้นเพื่อช่วยวิเคราะห์และคำนวณค่าพารามิเตอร์ทางไฟฟ้าพื้นฐานได้อย่างแม่นยำและรวดเร็ว มีวัตถุประสงค์หลักเพื่อคำนวณหาค่ากระแสไฟฟ้า ($I$) และกำลังไฟฟ้า ($P$) ที่เกิดขึ้นในวงจรตัวต้านทานตามกฎของโอห์ม ($V = IR$) เหมาะสำหรับนักเรียน นักศึกษา และผู้ที่ต้องการตรวจสอบผลการคำนวณในการทดลองวงจรไฟฟ้าเบื้องต้น

## วัตถุประสงค์ (Objectives)

- คำนวณหากระแสไฟฟ้า ($I$) ในหน่วยแอมแปร์ (A) ที่ไหลผ่านวงจรตัวต้านทาน
- คำนวณหากำลังไฟฟ้า ($P$) ในหน่วยวัตต์ (W) ที่กระจายในตัวต้านทาน
-ช่วยลดความผิดพลาดและประหยัดเวลาในการวิเคราะห์วงจรไฟฟ้ากระแสตรง
